- An independent second labeller for the 40 ambiguous / interpretive new claims, done from the blank workbook without AI help.
- Then report κ and adjudicate the disagreements.

### 2. Error analysis (once labels are final)
- Score A2, R and RG with the existing metrics: overall, by category, and by pattern from the design-intent file. Pattern scores are for analysis only.
- Look at the 10 changes RG blocked and the 12 it allowed: the harmful vs helpful split, by reason code.
- Code each suspicious case by type (table above) against the human label.
- Compare v2.0 → v2.1.1 only on the claims that ran under both (12 smoke claims).

### 3. Design questions for A3 v2.2 (not started; needs approval)
1. A Decidability check for evaluative predicates without a criterion.
2. Claim decomposition, so that the causal or scope part is judged separately.
3. Composite metric derivations (FCF, shareholder returns vs OCF).
4. Value-based quote checking for computed figures.

Any v2.2 change must be decided on the error analysis above, never by tuning to individual provisional labels.
