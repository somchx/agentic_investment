## 2. ประมาณการต่อ arm บน heldout-v1 (120 claims)

| Arm | ต้องเรียก LLM | ประมาณการ |
|---|---|---|
| A2 | 120 × initial | ≈ $2.40 |
| R (ฐานของทุก RG) | 120 × (plan + review + reconcile) | ≈ $14.20 |
| RG-0.1 / RG-0.2 / RG-0.2b / RG+C | replay จาก cache | $0 |

## 3. ความสอดคล้องกับ ledger cap เดิม

- **ledger `a3v2-dev-v0.2` เหลือ $2.38 ไม่พอสำหรับ heldout-v1** และผู้วิจัยสั่งไว้ว่าห้ามเพิ่ม cap $15
- **ทางเลือก (ต้องให้ผู้วิจัยตัดสิน):**
  - **(ก)** เปิด ledger ใหม่ `a3v2.2-heldout-v1` ที่มี cap ของตัวเอง เช่น $25 เป็นการทดลองใหม่ ไม่ได้เพิ่ม cap ของ ledger เดิม
  - **(ข)** ลดขนาดชุด
  - **(ค)** รันแค่บาง arm
- **ใช้ได้ภายใน ledger เดิม:** ขั้น decidability บน dev-v0.2 72 ข้อ (≈ $0.9–1.5) เพื่อ debug prompt และ schema ก่อน held-out
  - ผลจะเป็น in-sample ใช้ debug ได้อย่างเดียว
  - ต้องอนุมัติแยก
